Customer Churn & Retention Analysis

An end-to-end Data Analytics project focused on analyzing customer churn, retention patterns, customer behavior, and key factors influencing customer attrition. The project uses Python, SQL, and Power BI to clean and analyze customer data and create interactive dashboards for actionable business insights.

Key Analysis:

Analyzed overall customer churn and retention rates
Identified factors contributing to customer churn
Analyzed churn by contract type, tenure, services, and demographics
Identified high-risk and high-value customer segments
Studied monthly charges and customer lifetime value
Created an interactive Power BI dashboard for churn monitoring

Tools & Technologies:
Python | Pandas | NumPy | SQL | Power BI | Data Visualization

Project Outcome:
The analysis helps identify at-risk customers, understand churn drivers, and develop data-driven retention strategies to improve customer loyalty and reduce customer loss.
